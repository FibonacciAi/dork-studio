# Bring selected work into dork

Attach a source image through **Director**, **Imagine** or **Video**. Use **+ Char** or **+ Style** to save reusable references, and copy selected direction text into the editable fields.

To add existing saved media to the galleries, quit dork, copy the selected files into the folders below, and relaunch. Keep the originals and use a different name if a destination file already exists.

| Media | Default destination | Formats |
|---|---|---|
| Images | `~/.dork-studio/media/Images/` | PNG, JPG, JPEG, WebP |
| Video | `~/.dork-studio/media/Videos/` | MP4, WebM, MOV |
| Audio | `~/.dork-studio/media/Audio/` | MP3, WAV, OGG |

If you set `DORK_STATE_HOME`, use its `media/` folders instead. Enter your provider key in **Settings**. Attaching references is local; AI requests send selected inputs to the provider and are billed separately.
